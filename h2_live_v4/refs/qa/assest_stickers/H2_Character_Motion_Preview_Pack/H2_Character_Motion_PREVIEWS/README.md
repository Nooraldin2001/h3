# H2 Character — Motion research previews only

These are **low-resolution test videos, not production-grade alpha WebMs**.

- `entry_FRONT_VIEW_ONLY.webm`: front-facing walking; **wrong perspective** for requested bottom-center approach toward the stage.
- `exit_FRONT_VIEW_REVERSED.webm`: reversal of the same frames, **not real exit animation**.

- **Red and SOLD clips NOT delivered**; source art does not provide clean usable animation.
- Edges may contain noisy background/matte defects. Do not rename, integrate, or mark these as measured/production.

## Required production method

Use a rigged 3D character / motion captured footage / quality AI motion with consistent identity; genuine rear-view walk from bottom-center toward podium, turn to face audience, gesture at timed cue, turn and exit toward camera. Render RGBA image sequence at adequate resolution. Export alpha VP9 WebM; inspect on black and gold. Annotate real contact/gesture frames and UV anchors before enabling effects.
