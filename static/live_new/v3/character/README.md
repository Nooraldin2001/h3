# Gulf character assets (V3)

Place alpha WebM clips here (operator-triggered only — never autoplay):

- `point.webm` — character points at the plate
- `yellow.webm` — yellow card gesture
- `red.webm` — red card gesture
- `sold_stamp.webm` — SOLD stamp gesture

Until these files exist, the New Style control panel reports **asset missing** and the display does **not** fall back to a CSS mannequin as production output.

Optional debug CSS stub is gated behind a display flag and defaults to off.
